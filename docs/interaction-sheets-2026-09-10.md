# 余记：录入退出与统计明细面板

2026-09-10 · 原生 SwiftUI · 基于五年 500 条隔离样例

## 本次问题与改动

用户指出新建录入取消时的浮动确认框遮挡内容、键盘仍留在背后；统计需要多次跳页才能看明细，失去上游统计上下文。

### 录入退出

| 情景 | 新行为 | 数据边界 |
| --- | --- | --- |
| 新建内容没有变化，点关闭 | 直接退出 | 不新增写入 |
| 新建内容有变化，点关闭 | 本地保存草稿后退出，轻提示“草稿已保留，下次继续” | 不计入流水、余额和统计；重开或重启后恢复 |
| 点新建右上角清空草稿 | 底部数字区替换为清空确认，支持继续编辑 | 确认清空成功后才退出 |
| 编辑已有记录，无变化，点取消 | 直接退出 | 原记录与另一笔草稿均不变 |
| 编辑已有记录，有变化，点取消 | 底部数字区替换为“继续编辑 / 放弃修改” | 不出现浮动弹窗；不把修改伪装成已保留的草稿 |
| 编辑已有记录，保存成功 | 更新原记录，返回明细 | 保留独立的新建草稿 |
| 草稿写入或清空失败 | 留在录入页，显示错误 | 原有数据回滚；可以重试 |

退出确认出现时先收起系统键盘，隐藏金额键盘，并暂停上方字段编辑；继续编辑后恢复数字区。最大辅助字号下，确认内容单独滚动展示，文字完整换行，避免提示被省略；深色主按钮使用深色文字保证对比。以录入字段快照判断实际变化，忽略时间戳，避免加载备注就被认定为“修改过”。有未保存改动时阻止直接下滑丢弃，点关闭执行上述保存流程。

修正两项旧逻辑：编辑模式原先显示“保留草稿并退出”但并未保存修改；取消或保存编辑还会清除独立的新建草稿。

### 统计下钻

采用**七分屏 + 面板内联动**。首页总览、环形图选择、排行榜排序与滚动位置由原统计页保留。

1. 点分类排名、选中饼图后的明细入口或全部流水，打开约 70% 高度的明细面板。
2. 一级、二级分类各占一行，可横划；选中的一级自动滚到可见范围。点分类时直接更新同一面板的日期、金额、退款、净额与流水。
3. “全部二级”返回一级汇总；“重置”回到全部分类。无记录时明确展示空态，不回退到别的分类数据。
4. 按时间 / 按金额在面板内切换。点单笔才进入记录详情，面板自动展开；返回保留分类和排序。编辑保存后实时重算。
5. 同环比同样使用面板。“本期 / 基期”切换精确日期与流水；一级分类同时展示净支出差额，按差额绝对值排序，点选与下方明细联动，避免两套重复的分类入口。
6. 上拉或点展开可查看更大区域；点完成或下滑关闭回到原统计页。辅助大字号默认全高，内容可纵向滚动。

移除列表分区的额外留白，让 SE 七分屏首屏可以直接点击第一条流水；变化来源合并进分类选择。面板使用随浅深色切换的实色背景，避免 iOS 26 默认材质透出上游图表和数字。iOS 16.0–16.3 保留背景回退，不引入更高最低系统版本。

## 统计口径

复用既有 StatsEngine 范围、分类和退款查询，本次未改算术定义。支出占比按毛支出；退款按退款发生日期归原分类；净支出 = 支出 − 退款；收入不含转账。比较窗口、负基期、零基期、记录起点和闰日仍由五年样例与独立 oracle 核对。
