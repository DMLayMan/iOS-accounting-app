# 分类内联原生交付

日期：2026-09-10。当前交付范围：原生 iOS 实现 + 模拟器安装与验收。用户后续指定先用模拟器，真机签名流程已暂停。

## 产品行为

- 记账页直接展示一级一行、二级每页四列最多两行；按从左到右、从上到下排列，超过八项横划翻页。少量分类只占一行。
- 二级区域右侧常驻新增按钮。默认归入正在浏览的一级分类；记账状态新增后直接选中，编辑状态新增保留原选择。新增一级分类位于编辑状态的一级栏右侧。
- 一级、二级长按可拖动排序，支持跨行及边缘滚动到下一页；采用原生插入落点。取消拖动不提交，成功后可撤销排序。辅助功能也可执行向前/向后移动。
- 排序通过领域层校验完整的同级分类序列，再经 AppState 原子保存。重启保留顺序，失败回滚，不改变分类 ID、层级或账目引用。入口和全部分类使用一致顺序。
- 全部分类保留搜索与紧凑网格，选择后定位到对应一级及所在页。
- 名称、归属、归档、删除未使用分类沿用领域约束；记账页编辑入口直接可达。备注/搜索/编辑时隐藏金额键盘。
- 金额键盘为四行，长按加号可选择乘除、括号和清空，保留原有表达式计算能力。

## 实现

`InlineCategoryStrip.swift` 使用 UICollectionView、按行分页的自定义布局和原生 interactive movement。落点变化只在手势结束时调用领域排序；边缘滚动由显示刷新驱动。苹果提供了集合视图原生拖动与落点协调接口，参见 [Apple UIKit 文档](https://developer.apple.com/documentation/uikit/supporting-drag-and-drop-in-collection-views)。本实现使用 collection view 的本地 interactive movement，不传输分类数据。

`LedgerStore.reorderCategories` 仅接受指定账本、收支类型、父级内当前有效分类的完整排列；缺项、重复、跨分组、跨账本或过期列表均在写入前拒绝。

界面测试用 DEBUG 环境参数分配独立 JSON 文件，真实 RootView → Entry 弹窗启动。测试数据没有写入正常账本，正常启动继续使用既有数据库；未自动修改旧账本的默认分类目录。

## 运行

在仓库根目录执行 `./scripts/run-simulator.sh`，安装并启动默认 Yuji-Acceptance 模拟器。打开余记，点击中间「＋」即可体验。已有分类数量随账本而异，可用新增入口补充，顺序会保留。
