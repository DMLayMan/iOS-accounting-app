## 1. 基础规则

- 竖屏 iPhone，系统导航栈/TabBar；系统字体和 SF Symbols。背景使用 systemBackground / secondarySystemBackground，不用固定白色覆盖深色。
- 内容边距通常 20，账本组距 24，组内 8～16；普通按钮至少 44×44 命中。原生 Form 使用系统内边距，不手动拼桌面栅格。
- 正文 body/subheadline，次要 caption。AmountText 采用 rounded + monospacedDigit，ScaledMetric 跟随字号，单行最小缩放 0.5；可读性不足时先调行布局而非只缩字。
- 主动作 SolidActionStyle：最小高 50，圆角 16；浅色主题底白字、深色经调整主题底黑字，禁用中性底+次级字。非主动作优先文本/标准系统控件。
- 大字号：汇总列转单列，标题/日期允许分行，账单文字和金额改纵排，图表以文字排行提供可读等价信息。

## 4. 记账

- 全屏高度 sheet 内使用导航结构。取消/关闭位于左上，类型开关在金额之前，金额为第一视觉层级；日期、账户在金额下。
- 常规字号账户与日期同一行，账户名称可压缩省略、日期保留独立宽度；无障碍字号上下排列，账户至多两行。全名保留在选择器与朗读标签，不限制用户命名长度。
- 所有账户停用时，选择器明确“没有可用账户”，指向我的→账户新增或恢复；关闭记账保留输入，不呈现无解释的空白列表。
- 预算提示就近呈现；分类区一级一行、二级四列×最多两行。二级项高默认 62，行距 6；超八项分页。一级根据名称测量，最小宽 52，高 44。实际适配受大字号限制，不能把所有名称强制单字截断。
- 二级新增固定在右侧；全部分类与编辑入口仍可见。选中项用底色/下划线/文字共同识别；数量不超过四项时只用一行。图标与文案同组，不另造“快捷标签”。
- 自定义金额键盘固定在底部；顶部表单可滚动。备注聚焦后隐藏金额键盘；系统输入完成再恢复。普通页面没有一整行白底“记一笔”挡住内容。
- 保存按钮显示当前合法金额的保存状态。超额提示不改成危险操作警告；无有效金额不能保存。
- 新建关闭/后台留草稿，无气泡；返回初始空值清理旧检查点。编辑有修改取消在当前 sheet 底部出现继续/放弃，原内容禁用，金额/系统键盘收起。FormExitGuard 用于普通表单，草稿语义由 EntryView 自己负责；不承诺前台直接强杀的逐键保存。

## 5. 日期组件

`PeriodNavigation` 是完整共用组件，两个页面仅给无障碍 ID 不同前缀。上行月/年/全部/范围，下行两侧圆形方向按钮+中央年月入口。方向按钮真实命中 44pt，方向清晰，全部/范围不显示。没有第二套月份滚轮、局部滑动条或额外箭头。

日期面板 `PeriodPicker`：标题和取消 → 模式 → 年选择与月网格/年份列表/范围日期 → 适用时应用。月年直接点选提交，范围填写完整再提交。取消保持原期间，不把控件暂选状态写到父页面。年份受 1～9999 安全范围约束。

## 7. 预算与统计细节

预算提示共享一套计算和展示组件：整账本主条保留额度/已用/剩余或超额；分类默认最多两项超额，同页“全部 N 项”展开。健康规则不占据主阅读区域。记账预览必须带 replacingID，避免编辑已有金额重复计入。

饼图和紧凑排行在足够宽度时并列。默认四类可展开；大字号优先完整文字排行。筛选选中一级后下方展示二级按钮与取消入口；记录汇总和明细必须与筛选一致。点击排行不是新页面动作，不出现七分屏明细。

明细默认最多 20 条，可加载更多；金额/时间排序不改变上方分母。收入模式去掉退款排序。净退款月份保留负金额与退款明细，不能画负扇区。年度月柱图下方有可点击月份文本作为替代路径。

宿主将解析后的当前主题传入 `SupportAppearance` / `PromptSkin`；主动作浅色白字、深色黑字。辅助文字、未选圆圈、邀请右上关闭和「继续记账」使用 `Color.primary.opacity(0.7)`；支持页导航栏「关闭」跟随 `appearance.accent` 的主题色。支持页为 systemGroupedBackground / secondarySystemGroupedBackground，邀请为 systemBackground。不新增财务语义色或第二套主题。

自动邀请须等录入/退款/转账等现有 sheet、键盘、保存状态、错误和云加入提示退出后展示；前台状态与真实 UIKit 呈现状态共同决定可展示时机。100 笔是功能接入后成功的新建 ID 计数，不是账本列表条数。数据与一次消费契约见 [PRD](PRD.md#13-自愿支持开发者)，原生图集与各测试环境见 [支持交付](developer-support-2026-10-08/README.md)。

## 10. 复刻验收顺序

1. 用全新隔离账本核对默认页、空状态、中心记账、无改动取消。
2. 用五年 500 条夹具核对账本/流水/统计的不同汇总口径。
3. 核对选分类→改名/新增→记账→预算预览→保存→同页查账。
4. 核对饼图/排行/二级筛选/本期基期/单笔返回，不产生额外明细弹层。
5. 核对浅色、深色、自定义主题、小屏、最大字号、文字键盘和页内退出确认。
6. 核对读坏文件、写失败、恢复替换、回收站和历史引用。布局检查不能取代数据断言。
7. 用隔离模拟传输核对云开启/取消、暂停重启、只读、冲突副本、退出、错误及账号隔离；随后另做签名真实 CloudKit 与生产邀请验收。
8. 用隔离支持目录核对手动入口、未选择/已选择、本地 StoreKit 成功与 Ask-to-Buy 审批；核对 100 笔邀请在表单退出后出现、关闭/接受/重启不重复、已支持抑制、未知/待批准不自动付款、重新进入无历史锁、主动二次支持形成独立交易。小屏、深色、最大字号核对关闭、继续与支付可达；真机 Sandbox 另验。

新增页面需在此清单补齐入口、布局、提交和取消状态，并更新实际截图与验收记录；不要只更新 HTML demo。

## 2026-10-15：价格透明与测试环境边界

用户实际体验构建 9 后明确撤回“隐藏金额／去 App Store 确认”方案。支持页必须在主动购买前展示每档金额和币种，视觉与无障碍文案一致；默认不选，选中后按钮为“请一杯 · 金额”，仍在 App 内拉起 Apple 原生购买确认。不能通过隐藏金额、硬改符号或猜测汇率掩盖目录异常。

余记宿主统一显式使用 `SupportPricePresentation.localized`，不再按分发收据隐藏价格，移除旧 Debug 确认模式开关。金额来自 `Product.displayPrice`，不添加客户端价目表；当次目录复核、交易验签与收据持久化、重复支持和关闭重开保留。公共 SDK 的可选模式仍存在，但余记不调用。

恢复价格展示不代表美元问题修复。已安装构建 9 保留原行为，只作历史测试产物，不能用于送审；本地修改尚未分发。真实 TestFlight 商品报价与系统页/交易币种的一致性继续作为独立未关闭门槛，见 [价格方案撤回记录](release-validation-2026-10-15/price-transparency.md)。
