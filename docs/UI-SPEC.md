# 页面复刻清单

更新：2026-09-11。与 [PRD](PRD.md)、[DESIGN](../DESIGN.md) 一起使用。图集为当前原生模拟器截图，见 [当前页面图集](assets/current/index.html)。截图用于核对布局与状态，数据来自合成夹具。本文的布局单位为 pt，不将截图像素当作布局单位。

## 1. 基础规则

- 竖屏 iPhone，系统导航栈/TabBar；系统字体和 SF Symbols。背景使用 systemBackground / secondarySystemBackground，不用固定白色覆盖深色。
- 内容边距通常 20，账本组距 24，组内 8～16；普通按钮至少 44×44 命中。原生 Form 使用系统内边距，不手动拼桌面栅格。
- 正文 body/subheadline，次要 caption。AmountText 采用 rounded + monospacedDigit，ScaledMetric 跟随字号，单行最小缩放 0.5；可读性不足时先调行布局而非只缩字。
- 主动作 SolidActionStyle：最小高 50，圆角 16；浅色主题底白字、深色经调整主题底黑字，禁用中性底+次级字。非主动作优先文本/标准系统控件。
- 大字号：汇总列转单列，标题/日期允许分行，账单文字和金额改纵排，图表以文字排行提供可读等价信息。

## 3. 根页面与弹层

| 页面 | 自上而下布局 | 核心行为/状态 | 实现 |
| --- | --- | --- | --- |
| 账本 | 导航标题 → 当前名称 → 切换/新建 → 分隔 → 累计结余/收入/净支出/截止 → 账户合计与列表/转账 → 记录概况 → 草稿 | 不出现最近逐笔列表；看统计/查看流水切 Tab；归档显示状态 | LedgerHomeView |
| 流水 | 导航标题 → 共用时间组件 → 条数/汇总 → 当前筛选 → 日期分组流水 | 条件筛选、空状态；点记录进详情，返回不丢条件 | FeedView、TransactionRow |
| 统计 | 导航标题 → 同一时间组件 → 实际期间/净支出 → 预算 → 同环比 → 构成/排行 → 同页分类明细；年度月份趋势位于同比之后、构成之前 | 饼图/排行/二级过滤联动下方记录；比较展开替换同页分析上下文 | StatsView、CategoryAnalysisView |
| 我的 | 账本/账户/分类入口 → 数据/最近删除 → 外观反馈；iCloud 未开放 | 系统分组列表；不显示假的云开关 | MeView |
| 恢复入口 | 标题余记 → 读取失败说明 → 重新读取 → 选择备份恢复 | 不显示可记账 Tab；禁用坏库导出 | RootView storageFailure 分支 |

Tab 顺序固定；中心图标画布 38×28，圆角 10，plus 17 semibold。它是动作而非选中目的地，因此点击后原根页面保持选中。

## 4. 记账

- 全屏高度 sheet 内使用导航结构。取消/关闭位于左上，类型开关在金额之前，金额为第一视觉层级；日期、账户在金额下。
- 预算提示就近呈现；分类区一级一行、二级四列×最多两行。二级项高默认 62，行距 6；超八项分页。一级根据名称测量，最小宽 52，高 44。实际适配受大字号限制，不能把所有名称强制单字截断。
- 二级新增固定在右侧；全部分类与编辑入口仍可见。选中项用底色/下划线/文字共同识别；数量不超过四项时只用一行。图标与文案同组，不另造“快捷标签”。
- 自定义金额键盘固定在底部；顶部表单可滚动。备注聚焦后隐藏金额键盘；系统输入完成再恢复。普通页面没有一整行白底“记一笔”挡住内容。
- 保存按钮显示当前合法金额的保存状态。超额提示不改成危险操作警告；无有效金额不能保存。
- 新建退出留草稿，无气泡；编辑有修改取消在当前 sheet 底部出现继续/放弃，原内容禁用，金额/系统键盘收起。FormExitGuard 用于普通表单，草稿语义由 EntryView 自己负责。

## 5. 日期组件

`PeriodNavigation` 是完整共用组件，两个页面仅给无障碍 ID 不同前缀。上行月/年/全部/范围，下行两侧圆形方向按钮+中央年月入口。方向按钮真实命中 44pt，方向清晰，全部/范围不显示。没有第二套月份滚轮、局部滑动条或额外箭头。

日期面板 `PeriodPicker`：标题和取消 → 模式 → 年选择与月网格/年份列表/范围日期 → 适用时应用。月年直接点选提交，范围填写完整再提交。取消保持原期间，不把控件暂选状态写到父页面。年份受 1～9999 安全范围约束。

## 6. 表单与管理

| 页面 | 布局/初始高度 | 主要动作 | 退出/错误 |
| --- | --- | --- | --- |
| 新建/编辑二级分类 | 70% 可展开：预览图标、名称、一级选择、图标网格 | 保存，成功后原记账选中该分类 | 有修改页内确认；非法同名留输入 |
| 全部分类/管理 | 搜索、收入/支出、两级目录、已归档入口 | 选择定位、编辑、归档、无引用删除 | 先解释引用保护，不删除历史 |
| 新建账本 | 70% 可展开：名称、月/年预算、简短说明 | 键盘收起后底部“创建并使用” | 字段未填/预算非法禁用；有改动确认 |
| 预算管理 | 70% 可展开：账本月/年、分类规则列表、添加规则 | 全部保存；分类规则在同 sheet 内 push 编辑 | 暂存，取消不提交，历史规则保留 |
| 分类预算编辑 | 同一导航栈：月/年、分类范围、额度 | 添加/更新规则，回预算表单 | 非负最多两位小数；重复范围提示 |
| 账户编辑 | 原生 Form：名称、期初、起点、归档动作 | 导航保存 | 解析/起点错误就地提示；失败不关页 |
| 转账 | 70% 可展开：两端账户、金额、日期/备注、余额影响 | 明确金额保存 | 空表单取消直接退出；有改动页内确认 |
| 退款 | 70% 可展开：原金额/已退/剩余、此次金额、日期/账户/说明 | 明确舍入后保存 | 超可退额/日期错误，留在表单 |
| 交易详情 | 导航 List：类型+大金额、详情字段、退款关系、编辑/删除 | 单笔编辑、原支出/退款跳转 | 软删除确认；永久删除另确认 |
| 账本管理 | 新建入口、全部账本、每行更多菜单 | 改名、归档/恢复、删除空账本 | 删除说明目录/预算/草稿一并清除 |
| 最近删除 | 按删除日的记录，恢复/永久删除 | 原生明确动作 | 恢复校验，失败不移出回收站 |
| 数据管理 | 完整备份/选择恢复、上次恢复点、CSV、生成时间 | 原生分享/文件选择 | 读取失败时禁用导出；错误用实际状态 |
| 恢复预览 | 70% 可展开：校验结果、创建时间、数量、替换范围 | 底部“确认替换全部数据” | 取消不写；旧库副本写成功才可替换 |
| 外观与反馈 | 模式分段、主题 3 列（大字2列）、自定义入口、收支预览、反馈开关 | 即时选择预设；系统选色器完成后应用 | 不把主题当作收支类型色 |

## 7. 预算与统计细节

预算提示共享一套计算和展示组件：整账本主条保留额度/已用/剩余或超额；分类默认最多两项超额，同页“全部 N 项”展开。健康规则不占据主阅读区域。记账预览必须带 replacingID，避免编辑已有金额重复计入。

饼图和紧凑排行在足够宽度时并列。默认四类可展开；大字号优先完整文字排行。筛选选中一级后下方展示二级按钮与取消入口；记录汇总和明细必须与筛选一致。点击排行不是新页面动作，不出现七分屏明细。

明细默认最多 20 条，可加载更多；金额/时间排序不改变上方分母。收入模式去掉退款排序。净退款月份保留负金额与退款明细，不能画负扇区。年度月柱图下方有可点击月份文本作为替代路径。

## 8. 复刻验收顺序

1. 用全新隔离账本核对默认页、空状态、中心记账、无改动取消。
2. 用五年 500 条夹具核对账本/流水/统计的不同汇总口径。
3. 核对选分类→改名/新增→记账→预算预览→保存→同页查账。
4. 核对饼图/排行/二级筛选/本期基期/单笔返回，不产生额外明细弹层。
5. 核对浅色、深色、自定义主题、小屏、最大字号、文字键盘和页内退出确认。
6. 核对读坏文件、写失败、恢复替换、回收站和历史引用。布局检查不能取代数据断言。

新增页面需在此清单补齐入口、布局、提交和取消状态，并更新实际截图与验收记录；不要只更新 HTML demo。
