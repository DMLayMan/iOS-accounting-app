2026-10-16。基线 `9c353f1` / TestFlight 1.0（15）；本轮改动已打包为 [TestFlight 1.0（16）](../release-validation-2026-10-15/build16-delivery.md)，已进入原内部组；真机新 UI 安装与体验仍待用户确认。目标是完成日常任务时更容易看清和操作，保持用户已确认的 iCost 时间栏、两级分类、中间记账和统计同页下钻。

## 本轮修复

| 优先级 | 当前证据与影响 | 调整 | 用户动线 |
| --- | --- | --- | --- |
| P1 | 最大辅助功能字号下，账本名称装饰图标和云图标挤占宽度；累计收支标题、预算及看统计横排，文字碎裂 | 大字名称使用完整宽度，云入口独立文字行；三处章节统一标题/操作纵排，账户名/余额纵排 | 打开账本 → 看汇总 / 进统计，仍不增加层级 |
| P2 | 流水把作者、账户、日期、长备注拼成一行，备注几乎不可读 | 元信息与备注分开；普通备注最多两行，大字完整换行；金额靠齐标题，详情备注全宽左对齐 | 流水扫读 → 点单笔看完整备注 → 返回原筛选 |
| P2 | 默认统计的人员选择独占一行，与净支出及零退款公式重复占屏；收入/结余列起点不一致 | 默认人员菜单并入标题；金额下保留实际期间，有退款才展示分解；收入/结余等宽左对齐 | 选期间/人 → 读金额 → 点分类 → 同页明细 |
| P2 | 我的把“整理”“数据”各拆成一个入口的分组，偏好被推到页底 | 最近删除并入账本组，偏好提前，iCloud/备份/存储状态归为数据与同步；组间距 12pt | 我的 → 昵称/外观/管理，仍直接进入原页面 |
| P2 | 详情关联退款金额使用主题色，可能被误读为收入 | 使用已有退款蓝、支出橙语义色 | 在原支出和退款之间查看关联关系 |
| P3 | 记账收支选中态仅依靠颜色和字重；金额字形与其他页面不一致 | 18×3pt 短线补充选中提示，保留 AX selected；统一 rounded 等宽金额，备注点击区至少 44pt | 中间记账 → 输入金额/分类 → 保存，文字键盘继续互斥 |
| P3 | 流水行内和 List 额外上下留白叠加 | 保留内容上下 10pt、水平 20pt，移除额外 row inset，日期组间距 8pt | 给备注阅读留空间，无备注记录继续紧凑 |

统计对照使用相同的 iPhone 16 Pro / iOS 26.5 / 500 条合成数据 / 默认字号：AX 树中净支出从 y=321.0pt 到 283.0pt，收支去向标题从 644.7pt 到 606.7pt，上移 38pt。这个结果仅对应该条件，不推导为所有设备首屏可完整显示图表。

## 保留的设计与复用边界

- 时间栏、日期面板、底部 Tab、一级一行/二级最多两行的分类选择不改。统计筛选仍同页；查看单笔才导航。
- 新分类、账户、转账、预算仍使用原来的原生表单；取消保护与键盘完成栏复用已有实现。支持入口仍第一项，原报价/购买链路保留。
- 账本汇总继续区分累计结余与包含期初的账户余额，不重新加入最近流水。
- `StatsView.authorMenu` 同时服务紧凑摘要和完整人员行；`TransactionRow` 同时服务流水和统计；`sectionHeading` 仅复用账本三个章节，不抽象新的通用业务表单。
- 不改财务计算、存储结构、共享权限、作者归属、预算或支付 SDK；不添加服务端、动画依赖或额外弹层。
