# 文档索引与维护规则

当前生效基线（2026-09-11）：

1. [完整 PRD](PRD.md)：场景、功能、数据口径、退出与异常行为。
2. [页面复刻清单](UI-SPEC.md) + [设计规范](../DESIGN.md)：页面结构、组件尺寸/状态、颜色和操作路径。
3. [架构与扩展](ARCHITECTURE.md)：状态归属、写入/恢复流程、组件契约、扩展规则。
4. [本轮审查与回归](regression-2026-09-11.md)：缺陷处理、真实测试、剩余验证边界。
5. [当前原生图集](assets/current/index.html)：可随仓库分发的截图参考。
6. [产品上下文](../PRODUCT.md)：用户已经确认的取舍。

[iCloud 方案](icloud-sharing-plan-2026-09-10.md)是未实现的下一阶段设计。其他按日期命名的文档及 design-review 系列为历史迭代记录，包括曾经的标签、悬浮按钮、时间滚轮等被后续替代的方案；不作为复刻依据。旧 evidence 日志/图集保留本机，不把数 GB 测试产物提交到 Git。

功能或交互变更须同时更新 PRD、对应 UI 条目、架构契约（若影响共享组件）、回归记录和代表截图。测试数量只在回归记录维护；当前入口不要指向旧 demo。生成的工程以 `ios-app/project.yml` 为源，生成脚本与测试日期也要可重现。
