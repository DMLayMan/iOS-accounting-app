## 已发现并修复

1. **真实点击区不足**：账本切换、新建、预算、统计、账户管理；分类编辑、自动匹配、撤销、退出确认、统计排序/清除筛选/加载更多等控件将 44pt frame 放在按钮外。新增共用 `minimumTouchTarget()`，要求用于按钮/链接的 label 内部，避免只扩排版不扩交互。
2. **流水缺少完整朗读句**：共用 `TransactionRow` 改成单个语义元素，包含收支类型、分类、人民币金额、完整日期、账户、转入账户、共享记账人和完整备注。视觉仍保留紧凑行；不将截断备注当成读屏内容。
3. **收入错误带退款**：排行读屏根据收入/支出分别生成文案，收入不再播报退款；选中分类有状态与取消筛选提示。环形图的读屏激活与触摸一致，再次激活可取消。
4. **图标与按键语义不清**：分类预览及云差异共用中文图标名称；分类名输入有明确标签；小数点、减号、保存、完整记账日期有明确语义。金额数值仍保留，未改变计算、排序或数据格式。
5. **页内退出确认缺少焦点保护**：出现决定区时将被停用表单移出 AX 树，焦点请求定位确认标题；继续编辑恢复表单。覆盖共用表单退出组件与记账独立草稿确认。
6. **辅助文字偏淡**：主要记账、账本、流水、统计、分类和个人页面使用共用不透明辅助文字色，浅色 `#62666B` / 深色 `#B8BAC0`；财务色保持不变。原生颜色测试在 SwiftUI EnvironmentValues 中解析，对普通与分组背景验证 4.5:1。
7. **临时反馈没有主动播报**：Toast 与保存后的昵称同步状态发送系统 announcement，撤销按钮的真实点击区域扩到 44pt。分类排序说明补充辅助操作；实际发声仍待物理设备听读。

## 测试工具问题与证据保留

- 44pt AX frame 实际返回 `43.99999999999997`，尺寸断言采用 0.01pt 浮点容差；未放宽实际布局的 44pt 要求。
- SE 上“外观与反馈”位于首屏外，补记深色脚本先滚动到可见区域，再点击；产品按钮本身存在。修正后 3 项定向复验通过。
- 流水合并为单个读屏元素后，旧脚本不应继续查找内部 StaticText；改为通过稳定记录 ID 与完整朗读标签定位。
- 首轮诊断采集较慢，另一误启动批次在 UI 执行前中止；该批不计入覆盖。xcresult 必须等待 xcodebuild 完全结束后顺序导出，不能把读取尚未完成结果的失败当成产品失败。

- iOS 17.5 首轮两例在 AX 查询阶段崩溃，ips 堆栈为 `XCTAutomationSupport.runtime_issue_os_log_fault_callback → strcmp(NULL)`，同时有日志量隔离提示。保留两份原始 ips；收窄查询并单独重跑后均通过。研判：测试工具路径故障，未据此宣称所有崩溃风险排除，也未关闭运行时检查。
- iOS 26.5 的 `SKTestSession` 明确记录 `SKInternalErrorDomain Code=3`，配置、storefront 与事务清理均失败，但构造方法未抛出。未签名和本地 ad-hoc 签名都复现，签名并非已证实的修复。UI 收到真实 USD 目录，因此该批不算本地购买通过。新增 fixture 报价前置断言，不匹配立即失败，禁止继续自动购买；同一保护已在 iOS 17.5 成功批次验证。
- SE 大字号图标在固定底栏下仍被 XCTest 报为 hittable。脚本改为识别分类编辑 ScrollView，要求完整 frame 落在扣除底栏/键盘后的视口，显式点击中心并断言选中；最终填写/选图标/保存通过。没有放松名称长度或最大字号。
- iOS 17 先把 SwiftUI Color 桥接 UIColor 会冻结当前外观，旧颜色测试误报深色不合格；改用 `Color.resolve(in:)`，实际深色截图及比例均核对。

## 真机 VoiceOver 待验路径

在包含本轮修改的新候选包上，由本人开启旁白后执行；先在设置中确认关闭方式。仅使用隔离验收账本，避免无意修改日常数据。

1. 从账本进入记账，依次听到金额、账户、完整日期、一级/二级分类；数字、小数点、删除、保存可以辨认。
2. 分类转子动作向前/向后移动，检查位置与焦点；通过“全部分类”搜索并选中。新增分类时图标播报中文名。
3. 备注输入后收起系统键盘，回到数字键盘；取消编辑时焦点进入确认区，继续编辑可返回，底层失效控件不抢焦点。
4. 流水一笔一次聚焦，听到完整金额、类型、记账人及备注；详情、退款和返回路径可辨识。
5. 统计选择时期、记账人、收支与分类，听读选中态、排名和筛选后的明细；收入不夹带退款口径。
6. 同步状态、昵称待同步/完成/失败提示、支持档位与金额可听懂；只打开支持页，不确认支付。
7. 删除隔离测试记录后的临时撤销能被发现并完成；当前通用 Toast 自动关闭为 3.5 秒，真人听读时重点核对是否来得及，若不足则调整旁白模式的保留策略。
