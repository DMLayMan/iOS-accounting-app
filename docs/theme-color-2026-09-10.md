# 余记：主题与收支配色

日期：2026-09-10。用户目标：既有功能稳定后，统一配色细节，清楚区分收入和支出，并支持个人主题。实现范围为本地 iOS App；本轮不涉及 iCloud、签名或发布。

## 设计决策

进入「我的 → 外观与反馈」，轻点预设即应用并保存；也可进入系统选色器，通过网格、光谱或滑块选择任意颜色，点击关闭按钮应用。选色过程中不反复写文件；被杀进程或交互式下拉退出不提交尚未确认的颜色。

| 颜色角色 | 用途 | 规则 |
| --- | --- | --- |
| 主题 | 记账入口、导航、操作、分类选中态 | 青竹、海蓝、暮紫、烟玫、琥珀、石墨，以及自定义 RGB |
| 支出 | 支出金额、图标、净支出、年度支出柱 | 暖橙，减弱警报感；实际支出保留负号 |
| 收入 | 收入金额、图标、收入汇总 | 青绿，实际收入保留正号 |
| 退款 | 退款金额和负净支出 | 蓝色，避免退款被误读成收入 |
| 中性 | 转账、账户余额、累计结余、同环比结论 | 跟随系统深浅色；不把增加/减少简单评价为好坏 |
| 分类构成 | 饼图、排行图例 | 保留分类色和名称/金额/百分比，不随操作主题改变分类含义 |

浅色保持白底，深色使用系统黑色及分组背景。强调色只落在有意义的位置，避免正文、大面积背景和所有金额一起变成主题色。选中项仍用勾选、下划线或底色；收支同时有文字与金额符号，不依赖颜色单独表达。

原生色彩及多重提示原则参考 [Apple Color HIG](https://developer.apple.com/design/human-interface-guidelines/color) 与 [Accessibility HIG](https://developer.apple.com/design/human-interface-guidelines/accessibility/)。主题应用参考 [SwiftUI accentColor](https://developer.apple.com/documentation/swiftui/color/accentcolor)，系统选色入口使用 [UIColorPickerViewController](https://developer.apple.com/documentation/uikit/uicolorpickerviewcontroller)。这些是平台依据，实际布局以本次原生验收为准。

## 逐项改动

- 账本：累计收入青绿、累计净支出暖橙，余额和结余中性，预算与管理操作使用主题色。
- 流水与单笔详情：收入/支出/退款/转账的图标与金额统一分色，保留正负号；日结余不被误标为收入。
- 统计：净支出、收入摘要、饼图中心金额和年度柱图与交易语义一致，分类筛选和预算管理使用主题色。时间栏继续共用 PeriodNavigation。
- 记账：切换收入/支出后金额和类型提示相应变化；分类一级、二级选中项及底部保存键跟随主题；禁用保存按钮使用中性背景与次级文字。
- 外观设置：六种可读的低饱和预设，两行展示；最大无障碍字号改为两列。跟随系统、浅色、深色仍由原生分段控件选择，保留触觉和减弱动态选项。
- 本地设置：旧账本缺少新字段仍可解码，默认青竹；未知主题及非法 RGB 值安全回落。更改主题不修改金额、分类和账本记录。

## 审查中关闭的问题

1. 收入、操作按钮共用绿，支出仅黑色：改为独立金融语义色，按钮有单独主题规则。
2. UIKit 分类组件还写死绿色：显式接收与 SwiftUI 一致的主题，并在颜色变化时刷新，不重置分类或拖拽顺序。
3. 系统选色器挂在 Form 子组导致呈现位置不稳定；移到页面后，SwiftUI sheet 容器又隐藏了关闭按钮：改由稳定页面宿主直接呈现系统 UIColorPickerViewController。保留第一次失败记录，不用测试成功截图掩盖此前失败。
4. 禁用保存键的白字在浅灰底上不清楚：改为次级文字与中性底；深色有效主按钮使用黑字。

## 验收记录

最终机器可读结果和测试日志见 [verification.json](../evidence/theme-color/verification.json)；可比较的原生页面见 [截图验收页](../evidence/theme-color/index.html)。不将 HTML 图库当成 App 原生运行。

- `swift test`：105 项通过，包含旧设置解码、自定义设置往返、未知字段回退、500 条样例记录在主题保存前后保持一致。
- 主题对比度：六种预设与极端色/128 个确定性样本，在深浅基础、分组、选中背景上检查至少 4.5:1；原生 UIKit 解析后的收支语义色另行检查。
- 原生：iPhone 17 Pro 与 iPhone SE 3，iOS 26.5。验证选择主题、切换账本/流水/统计/记账、收入与支出、深色、最大无障碍字号、进程重启后的保存、自定义任意色确认，以及选色中被打断不覆盖原主题。
- 数值回归：2026 年 8 月净支出 ¥7,574.66、流水 15 笔；另跑流水/统计时间栏统一及模式切换回归。
- 各测试使用新 UUID 的隔离数据；原生宿主单测也设置独立 session，未清空个人 ledger.json 或复用既有体验 session。

## 实际限制

本轮仅模拟器，尚未验收真实屏幕色差、真机触觉、VoiceOver 实际朗读或长期主观满意度。对比度断言覆盖定义的颜色与背景，不代表所有系统透明材质、禁用态或整个 App 都完成 WCAG 认证。当前主题随本地设置保存；云端同步尚未实现。没有提交、推送、发布或替换个人真实账本。
