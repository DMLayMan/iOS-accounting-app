# 无箭头时间导航原型

本轮入口：`http://127.0.0.1:8770/demos/time-navigation-v2/index.html`。

保留第一版用于比较。第二版用明确的月份/年份按钮替换翻页与下拉箭头，保留日历入口和原位时间面板。月份横滑仅浏览，点击才更新。

详见 [本轮设计说明](../../docs/time-navigation-refinement-2026-09-10.md)。日期、范围、金额模型与基础样式引用第一版；当前目录的 app.mjs 是独立交互版本，未改第一版入口或原生页面。

数据为既有隔离样例，只读；没有用户数据写入与服务器同步。继续使用固定演示日期 2026-09-10，五年可选范围。保留相同统计/流水联动、分类筛选、空状态和范围校验。

## 验证

走查结果与原型截图记录于本目录；不作为 Simulator、触觉或 VoiceOver 的验收结果。原生版本仍保持原状。

2026-09-10 实际浏览器结果：

| 项目 | 结果 |
| --- | --- |
| 顶部符号 | 时间栏只剩一个 calendar 图标，无左右/下拉箭头 |
| 默认月份可见与命中 | 9 月选中项完整位于横向可视范围内，按钮高度 44 px |
| 相邻月份与 Tab | 点 8 月应用完整 8 月；切流水继续保留 8 月 |
| 键盘 | Tab 仅一个月份停靠点；左方向键把焦点移到 8 月但仍选择 9 月；Enter 后才应用 8 月 |
| 历史月份 | 日历定位 2024.02，切流水显示 7 笔、净支出 ¥5,169.51 |
| 跨年 | 2026.01 旁显示带 2025 年份的 12 月；点击正确进入 2025.12 |
| 年模式 | 日历切按年、选 2024，顶部展示直接点选的年份列表和回本年 |
| 错误/取消 | 反向范围禁用应用；取消后保留 2024.02 |
| 全部/自定 | 全部 470 笔；2022.12.31–2023.01.15 显示首尾两笔 |
| 小屏深色大字号 | 月份与日历可达，跨年标识可读，当前选择保持可见 |

JS 语法检查与 `git diff --check` 通过。复用的金额/期间模型本轮未改，不重复运行上一版测试来增加通过数字。两轮集中视觉检查已完成，第二轮确认修复了初次布局后选中项右端裁切；真实 iPhone 手指横滑和 VoiceOver 尚未实测。
