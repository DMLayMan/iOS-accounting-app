# 余记：记账页内联分类 Demo

更新：2026-09-10，交互 Demo 05。仅更新浏览器原型，未替换原生 iOS 界面。

体验：http://127.0.0.1:8770/demos/category-inline-v1/index.html

## 布局与顺序

一级分类一行。二级分类每页四列，先从左到右填满第一行，再排第二行；每页最多八项，超出横划翻页。四项及以内只占一行，因此「娱乐」的电影演出、游戏、运动健身、旅行休闲横排展示。

「＋ 新增」固定在二级区域右侧，独立于可排序项目。不占分类名额、不随翻页消失，也不要求先进入编辑。新增默认归入当前一级分类；从记账状态新增后直接选中，从编辑状态新增则保持原有选择。金额始终保留。

页面下方显示当前已选分类路径。浏览其他一级分类不会自动改变归属。「全部分类」可搜索一级或二级名称，选择后返回对应一级及二级所在页。备注仅记录信息，文本输入时收起金额键盘。

## 整理分类

- 普通状态：长按约 420 ms 拿起一级或二级分类，拖动至目标位置后松手。
- 编辑状态：直接拖动调整顺序；轻点仍可改名、调整二级归属、归档或删除未使用分类。
- 二级分类可跨行拖动，停留在区域边缘约 700 ms 自动翻页继续排序。一级分类拖到边缘会连续滚动。
- 松手提交顺序，提示中可撤销。拖动中按 Escape 取消。手动顺序用于入口与全部分类列表；无自动统计重排。
- 键盘操作：焦点位于分类时，空格拿起，方向键移动，Enter 或空格放下，Escape 取消。
- 新增一级分类仍在编辑模式的一级导航末尾。

## 范围与待验证
