# 时间导航研究原型

只读交互研究，不是已经安装到 Simulator 的原生版本。产品研究见 [调研文档](../../docs/time-navigation-research-2026-09-10.md)。

访问：http://127.0.0.1:8770/demos/time-navigation-v1/index.html 。沿用既有本地静态服务器，没有启动新的长期服务。

## 已实现的演示

- 同一时间栏；月/年连续翻页，回当前期间保留粒度。
- 原位年月网格，选月/年后关闭；取消不提交。
- 自定义范围草稿、错误校验和应用；全部时间。
- 统计/流水共享期间，统计分类筛选联动明细；只显示实际日期范围。
- 本月 4 笔 / ¥501.05，闰年 2024 年 2 月 7 笔，全部当前账本有效记录 470 笔；源文件共有 500 条记录，包含其他账本和删除数据。
- 原型自己的小屏、深色、大字号开关。大字号是网页模拟，不能代替 iOS Dynamic Type 验收。

数据来源为 `Fixtures/stats-500.json`，没有写接口、持久化或第三方资源请求。刷新重置选择。演示固定当前日期 2026-09-10；只展示已有五年的可选年份，非通用生产日期组件。

## 验证与边界

运行 `node demos/time-navigation-v1/verify.mjs` 校验期间解析与已知样例金额，日志保存到 `verification.json`。

浏览器走查：当月默认、相邻月、2024.02、Tab 共享、按年、取消不提交、范围反转拦截、跨年范围与全部、小屏深色大字号。实际走查结果与截图在本目录。

### 2026-09-10 走查记录

12 项演示逻辑校验通过，详见 [verification.json](verification.json)。这是原型自己的校验，不是 YujiCore/原生回归测试。

| 浏览器操作 | 观察结果 |
| --- | --- |
| 默认 → 上个月 → 回本月 | 9 月范围截至 9 月 10 日；8 月显示完整 8 月；返回恢复 9 月 |
| 日期 → 2024 → 2 月 → 流水 | 标题和范围保留为 2024.02.01–02.29，7 笔、净支出 ¥5,169.51 |
| 日期 → 按年 → 2024 → 回本年 | 返回 2026 年，范围 2026.01.01–09.10，保持年模式 |
| 开始 2025.01.05、结束 2024.12.25 | 结束日期错误就地出现，「应用日期范围」禁用；取消后仍是原先的 2024 年 |
| 自定 2022.12.31–2023.01.15 → 流水 | 首尾两笔均显示，支出/退款各 ¥12,000，净支出 ¥0.00；统计没有硬算同环比 |
| 全部时间 | 截至今天的当前账本 470 笔 |
| 2023 年 2 月 | 0 笔与空状态，回本月可恢复 |
| 深色 + 375 px 小屏 + 网页大字号 | 年份可选，月份重排为 3 列，面板内部可滚动，底部 Tab 保持可达 |
